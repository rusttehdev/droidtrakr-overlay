# Security Policy

## Reporting a vulnerability

Please do **not** publish credentials, session material, personal information, or an exploitable vulnerability in a public issue.

Report security concerns privately through the contact method listed at:

https://droidtrakr.com/contact

Include the affected version, reproduction steps, impact, and any suggested mitigation. Please allow reasonable time for investigation before public disclosure.

## Release safety

Official releases are distributed only through `droidtrakr.com`. Verify package hashes against the HTTPS release manifest before running an installer or update.
