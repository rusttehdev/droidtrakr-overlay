# Privacy Notes

DroidTrakr uses your account to synchronize tracker progress and group information between the website and Windows overlay.

The client may transmit:

- Account authentication requests
- Rebirth and checklist progress
- Group/team selections
- Messages you explicitly send
- Secret Vendor Limited Deal selections
- Release/update requests

The client does not intentionally collect Fortnite credentials, control input, inject code into Fortnite, or read Fortnite process memory.

For the current website privacy policy, see:

https://droidtrakr.com/privacy
